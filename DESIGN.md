# Elmasriya website design context

Read alongside AGENTS.md. This document records the current approved direction.

- Static Arabic HTML/CSS/JavaScript website for a manufacturer of metal food barrels, rings and lids.
- Preserve the original full-photo home hero, overlaid header and existing content layout. The two alternative hero designs were rejected.
- Primary color: #1a2b51. Secondary green: #1f7a45. Reuse the existing CSS variables, logos and supplied images.
- Use Tajawal throughout, including form controls. Documents use lang="ar" and dir="rtl".
- Use the requested term «المراكز» consistently. Preserve business names, contact details and product specifications.
- Mobile menu button stays at the far left. The backdrop must remain behind the drawer. Keep links usable by pointer and keyboard.
- The quote form is a static demonstration, without a sending backend. Never claim a request was sent. Backend integration is separate work.
- Main pages: index.html, about.html, products.html, product-barrel-220.html, product-barrel-240.html, product-chamber.html, product-lid.html, contact.html.
- Files containing .before are historical snapshots; do not treat them as the current design or create additional public snapshots for routine changes.
- Validate local references and JavaScript changes. Use browser checks when available and report any missing visual verification honestly.
